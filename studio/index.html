Recording on iPhone

  1. Add Screen Recording to Control Centre (Settings → Control Centre) if it isn't there.
  2. Tap Record mode here, then start screen recording.
  3. Tap the screen. It plays after a short pause and ends on the winner.
  4. Trim the start and end in Photos, then upload with a trending sound.
